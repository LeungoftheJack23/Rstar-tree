How to use:

1. Before starting the script, you need to install the following packages using the command `pip install noise`
2. Start the script using the command `python Rstar-tree.py`
3. Enter either the point file or (points, generate point method), maximum children in a tree, method number and repeat times as requested in the command prompt
4. It will show the result in the command prompt and save the result in separate files in the results directory (and the point file if it is not from a loaded file)

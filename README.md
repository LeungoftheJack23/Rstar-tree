History:

2025/04/26 Implement R-tree structure and a test case in Rstar-tree.py

2025/04/28 Managed scripts into different directories (classes). To use it, run Rstar-tree.py as the main script.

How to use:

1. Start the script using the command `python Rstar-tree.py`
2. Enter the points, maximum children in a tree, method number and repeat times as requested in the command prompt
3. It will show the result in the command prompt and save the result in separate files in the results directory
